ConfigReview · Step 3
⚡ AA Smart Wallet Infrastructure
ERC-4337 Account Abstraction infrastructure is automatically deployed with this preset to support smart wallet functionality:
  • ERC-4337 EntryPoint predeploy
  • MultiTokenPaymaster predeploy for gas fee sponsorship
  • SimplePriceOracle predeploy for token price feeds
  • 1 TON deposited to EntryPoint for MultiTokenPaymaster gas sponsorship
  • Bridged USDT deployed on L2 via OptimismMintableERC20Factory
  • USDT registered with MultiTokenPaymaster (3% markup)
  • TON/USDT price auto-updated from CoinGecko every 10 min — no manual oracle management needed
  • EntryPoint TON balance auto-refilled from admin wallet when below 0.5 TON (top-up 5 TON)
  • aa-operator Docker service runs continuously to manage the above two tasks
USDT.approve(MultiTokenPaymaster, amount) must be called before submitting UserOps with this paymaster.

Purple card shown for Gaming/Full preset always. Non-TON bullet items shown only when fee token ≠ TON.
