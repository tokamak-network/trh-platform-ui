⚡ AA Paymaster Auto-Configuration
USDT is selected as the fee token. Since TON is the L2 native gas token, AA (Account Abstraction) infrastructure will be automatically configured after the L2 network starts:
•1 TON deposited to EntryPoint for MultiTokenPaymaster gas sponsorship
•Bridged USDT deployed on L2 via OptimismMintableERC20Factory
•USDT registered with MultiTokenPaymaster (3% markup)
•Uniswap V3 WTON/USDT pool created and initialized on L2
•UniswapV3TwapOracle deployed — live price feed, no manual updates needed
Users must call USDT.approve(MultiTokenPaymaster, amount) before submitting UserOps with this paymaster.
⚠️ TON 잔고 유지 필요 (현재 UI에 없음 → 추가 필요)

현재 UI 갭 분석:
1. BasicInfoStep (Step 2)에 fee token 선택 시 인라인 안내 없음 — USDT/ETH 선택 직후 AA 구성 및 TON 잔고 필요성에 대한 설명이 Step 3까지 미뤄져 있음. Screen C처럼 선택 즉시 토큰 정보 박스를 노출하는 것이 UX에 유리.

2. TON 잔고 유지 안내가 ConfigReview(Step 3)에 없음 — 현재 "1 TON deposited to EntryPoint" 항목은 있지만, 이후 잔고 소진 시 대응 방법(deposit 방법, 모니터링)에 대한 안내 없음.

3. 오라클 자동화는 이미 구현 완료: setupUniswapV3Oracle이 L2 시작 후 자동 실행되며 운영자 개입 불필요. 단, Uniswap V3 풀에 초기 유동성(LP)이 없으면 TWAP이 동작하지 않고 spot fallback만 사용됨 — 추후 LP 공급 전략 고려 필요.
