⚡ AA Paymaster Auto-Configuration

USDT is selected as the fee token. Since TON is the L2 native gas token, AA infrastructure will be automatically configured after the L2 network starts:

  • 1 TON deposited to EntryPoint for MultiTokenPaymaster gas sponsorship
  • Bridged USDT deployed on L2 via OptimismMintableERC20Factory
  • USDT registered with MultiTokenPaymaster (3% markup)
  • TON/USDT price auto-updated from CoinGecko every 10 min — no manual oracle management needed
  • EntryPoint TON balance auto-refilled from admin wallet (top-up 5 TON when below 0.5 TON)
Users must call USDT.approve(MultiTokenPaymaster, amount) before submitting UserOps with this paymaster.

AA Paymaster 백엔드 자동화 아키텍처 (trh-sdk)

배포 완료 후 ThanosStack이 백그라운드에서 실행하는 자동화 구성요소들

1. setupAAPaymaster() — L2 시작 후 1회
① 1 TON → EntryPoint.depositTo(MultiTokenPaymaster)
② USDT인 경우: OptimismMintableERC20Factory로 bridged USDT 배포
③ MultiTokenPaymaster.addToken(USDT, SimplePriceOracle, 3%)
2. startPriceUpdater() — 상시 백그라운드
🌐 CoinGecko API로 TON 시세 조회
• 10분마다 폴링 (무료 API, 키 불필요)
• 가격 변동 >2% → 즉시 온체인 업데이트
• 23시간 경과 → 강제 업데이트 (staleness 방지)
• ETH: TON/ETH × 1e18
• USDT/USDC: TON/USD × 1e18
→ SimplePriceOracle.updatePrice(price)
3. startEntryPointRefillMonitor() — 상시 백그라운드
💰 5분마다 EntryPoint 잔고 확인
• 임계값: 0.5 TON
• 잔고 < 0.5 TON → 자동 5 TON 충전
• admin 지갑 잔고 < 2 TON → 경고 로그
• sync.Mutex로 중복 충전 방지
→ EntryPoint.depositTo(MultiTokenPaymaster, 5 TON)
배포 후 자동화 플로우
L2 시작 → setupAAPaymaster() [1회] → startPriceUpdater() [goroutine] + startEntryPointRefillMonitor() [goroutine] → ctx.Done() 시 종료
